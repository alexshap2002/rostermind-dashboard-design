# Варіант 7 — «Неон»

Гілка `design/v7-neon`. Сторінка `/main-branch`.

## Ідея

Темна робоча консоль за референсом користувача (друга картинка): глибокий чорно-бірюзовий фон, ліворуч
темна панель навігації з іконками, зверху заголовок і перемикач розділів, чотири **насичені градієнтні
картки показників** (бірюзова, фіолетова, помаранчева, рожева) з іконкою в кружечку, великим числом і зміною
до попереднього періоду, нижче — три темні картки зі списками й **статусними пігулками з крапкою**, далі темна
таблиця зі статусами й діями.

Референс словами: «Admin Dashboard» партнерської мережі — sidebar з пунктами меню, кольорові KPI-картки
«Total Affiliates / Active Brands / Active Deals / Average ROI» з «+2.0 % Last month», три картки «Recent …»
з пігулками «Active / Pending», таблиця з колонками Status і Actions.

## Де свідомо відступили від брифу

Бриф (§6) просить зберегти теплий паперовий характер RosterMind, один теракотовий акцент і не перетворювати
дашборд на «шаблон із різнокольоровими градієнтами». **Цей стиль обрав користувач явно**, тому візуальні
правила §6 тут не діють: тема темна, акцент бірюзовий, картки показників — чотирикольорові градієнти.
Усе інше з брифу й `CLAUDE.md` виконано: структура А–Д, чесні числа з `mockApi.ts`, карта переходів,
стан у URL, статуси текстом (не лише кольором), зростання зарплат нейтрально, персональні списки лише за
явним кліком, кольори — лише токенами, контраст ≥ 4,5:1, адаптив без горизонтального прокручування.

## Що на екрані

**Ліва панель (232 px, sticky під шапкою):**
- «RosterMind · мережа шкіл» і пункти з іконками: **Огляд** (прокрутка вгору), **Філії** (до таблиці),
  **Заняття / Відвідуваність / Зарплати** (відкривають панель відповідного показника), **Проблеми**
  (розгортає «Детальні звіти» на вкладці «Проблеми» і прокручує до них);
- **Період** — вертикальний список пресетів зі справжніми датами («Цей місяць · 1–20 жовтня»), «Свій період»
  розкриває поля дат; активний — бірюзова підсвітка;
- **Філії** — чекбокси з кількістю дітей і бейджем кількості невідмічених уроків (лічильники беруться з KPI
  за той самий період без фільтра філій — `kpiAll`, тож не зникають, коли філію знято з вибору);
- внизу «Оновити» та «Excel».

**Робоча зона:**
- заголовок «Мережа шкіл», підрядок «період · філії · оновлено», текст порівняння; праворуч перемикач
  «Огляд / Філії / Звіти» (ті самі переходи, що й у навігації);
- 4 градієнтні KPI-картки — уся картка кнопка → панель «по філіях»; зміна «▲/▼ … до попереднього періоду»
  текстом (для зарплат — нейтральним кольором); чипи «+N нових →», «N не відмічено →» — окремі кнопки;
- три картки: **На зараз · 30 днів** (сигнали з пігулками Увага / Ризик / Сьогодні → свої вибірки),
  **Стан філій** (назва → «Огляд філії», пігулка «усе гаразд / N не відмічено / відвідуваність впала» → показник
  філії), **Сигнали за період** (невідмічені згорнуто по філіях, падіння — окремо; до 5 рядків → «Усі сигнали»);
- темна таблиця філій: колонки за брифом, сортування, рядок «Уся мережа», колонка **Статус** з пігулками,
  «Працювати у філії» ghost-кнопкою;
- «Динаміка за період» (лінія бірюзова, стовпчики напівпрозорі) і «Детальні звіти».

  Нових даних від сервера не потрібно (`docs/BACKEND_NEEDS.md` порожній).

## Адаптив

- ≤ 1100 px — панель навігації стає блоком над даними: пункти в рядок, період і філії — чипи; KPI 2×2;
  три картки в стовпчик.
- ≤ 900 px — таблиця філій → картки з тими самими полями й переходами.
- ≤ 760 px — KPI в один стовпчик.
- Перевірено на 1440 / 1280 / 768 / 390 px: горизонтального прокручування немає.

## Перевірено

- `npm run typecheck`, `npm run build` — чисто.
- Скриншоти: перший екран 1440×900 (навігація, 4 KPI, три картки й заголовок таблиці видно без прокручування),
  1440 / 1280 / 768 / 390, бічна панель (`?panel=lessons`), період «сьогодні» (стани «порівняємо завтра»,
  «усе гаразд», «немає занять»).
- Контраст розрахунково: білий на світлішому краю кожного градієнта ≥ 5,2:1; підписи `--text-3` на картках
  ≈ 6:1; темний текст на бірюзовій кнопці ≈ 8,7:1.

## Припущення й що лишилось

- Навігаційні пункти «Заняття / Відвідуваність / Зарплати» відкривають панель показника (окремих сторінок
  мережі для них у програмі немає); «Філії й оплата» лишається в шапці.
- На екранах нижчих за ~820 px у висоту ліва панель прокручується всередині (sticky з `max-height`).
- Шапка `.topnav` лишилась як у програмі (активний пункт теракотовий) — це бренд RosterMind; за бажання
  можна перефарбувати в бірюзовий тим самим токеном.
- Аудит з екранним читачем не робився; семантика, фокус і контраст — за токенами.
