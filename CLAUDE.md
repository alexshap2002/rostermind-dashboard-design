# CLAUDE.md — RosterMind: дизайн дашборду мережі

Це **лише фронтенд** RosterMind (облік гуртків і позашкільних закладів) — копія для роботи над дизайном.
Сервера, бази й справжніх даних тут немає: усі дані вигадані й живуть у `src/demo/mockApi.ts`.
Мова інтерфейсу — українська.

## Завдання

Зробити головний дашборд власника мережі шкіл зрозумілим і гарним: за 10 секунд видно, скільки дітей,
як працюють філії, відвідуваність, скільки занять проведено й зарплат нараховано, де потрібне втручання.
Повний бриф — **`docs/BRIEF.md`** (читай перед роботою). Поточна версія — сторінка `/main-branch`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 → одразу /main-branch, з вигаданими даними
npm run typecheck    # TypeScript має бути чистим
npm run build        # збірка в dist/ (те саме робить Vercel)
```

## Де що

- `src/features/mainBranch/` — дашборд мережі:
  - `MainBranchPage.tsx` — сторінка: період і філії, «На зараз», 4 показники, таблиця філій, графік, звіти;
  - `NowStrip.tsx` — рядок «На зараз»; `BranchCompare.tsx` — таблиця філій; `TrendPanel.tsx` — графік;
  - `MetricPanel.tsx` — бічна панель розбивок; `ReportTabs.tsx` — детальні звіти; `metrics.tsx` — підсумки й «зміна»;
  - `api.ts` — **типи відповідей справжнього сервера**.
- `src/demo/mockApi.ts` — вигадана мережа (3 філії, ~5 місяців занять); підміняє `fetch`. `src/demo/DemoStub.tsx` — заглушка для інших сторінок.
- `src/styles/index.css` — уся стилізація: токени в `:root`, класи дашборду мережі — секція «Мережа шкіл» (`.nd-*`).
- `src/lib/format.ts` — числа, гроші, дати, відмінки (`pluralUk`); `src/lib/icons.tsx` — іконки (SVG, без емодзі).
- `src/components/` — шапка (`layout/TopNav.tsx`), спільні елементи (`admin/primitives.tsx`).
- `.claude/skills/warm-ink-design/` — правила дизайн-системи (кольори, шрифти, класи).

## Правила

1. **Не змінюй форму даних з `api.ts`.** Це контракт справжнього сервера — тоді роботу можна перенести в програму без бекенду.
   Потрібні нові дані — додай їх у `mockApi.ts` **і** запиши в `docs/BACKEND_NEEDS.md`: яке поле, звідки береться, навіщо.
2. **Чесні числа:** нічого не вигадуй поза `mockApi.ts`; «немає даних», «0» і «ще не відмічено» — різні стани.
   Відвідуваність мережі — присутні / очікувані по всіх філіях, а не середнє відсотків філій.
3. **Кольори — лише токени** з `:root`; один акцент (теракота) для дій; статуси — текстом/значком, не лише кольором;
   зростання витрат на зарплати — нейтрально.
4. **Доступність і адаптив:** звичайний текст ≥ 4.5:1, клавіатура й видимий фокус, 1440 / 1280 / 768 / 390 px без горизонтального прокручування.
5. **Персональні списки** (діти, вчителі) на рівні мережі — лише за явним кліком.
6. Мінімум нових залежностей; стилі — в `index.css` окремою секцією з коментарем.
7. Коміти невеликі, з поясненням українською. Нову ідею (інший варіант дашборду) — в окремій гілці.

## Показати іншим (Vercel)

Репозиторій уже налаштований (`vercel.json`): на vercel.com → **Add New → Project → Import** цей репозиторій →
нічого не міняти → **Deploy**. Кожен push у гілку дає нову адресу попереднього перегляду, push у `main` — оновлює основну.
З терміналу: `npx vercel` (попередній перегляд) або `npx vercel --prod`.

## Чого тут немає

Сервера, входу, справжніх філій, дітей і грошей. Поза `/main-branch` — заглушка «у демо недоступно».
Для інших екранів треба спершу додати вигадані дані в `mockApi.ts` (за типами з `src/features/<розділ>/api.ts`).
