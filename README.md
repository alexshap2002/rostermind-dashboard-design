# RosterMind — дизайн дашборду мережі

Фронтенд RosterMind для роботи над дизайном головного дашборду власника мережі шкіл.
**Без сервера й без справжніх даних** — усе вигадане (`src/demo/mockApi.ts`).

## Швидкий старт

Потрібні [Node.js 22](https://nodejs.org/) і (за бажанням) [Claude Code](https://claude.com/claude-code).

```bash
git clone <адреса цього репозиторію>
cd rostermind-dashboard-design
npm install
npm run dev
```

Відкрийте http://localhost:5173 — одразу відкриється дашборд мережі з вигаданими даними.

## Робота з Claude Code

У теці репозиторію запустіть `claude`. Claude сам прочитає `CLAUDE.md` (контекст, правила, де що лежить)
і скіл дизайну `.claude/skills/warm-ink-design`. Почніть, наприклад, так:

> Прочитай docs/BRIEF.md і подивись поточний дашборд (src/features/mainBranch). Запропонуй, що покращити, і зроби це в новій гілці.

## Показати на Vercel

1. Зайдіть на [vercel.com](https://vercel.com) (можна через GitHub) → **Add New → Project**.
2. Оберіть цей репозиторій → **Deploy**. Налаштування вже в `vercel.json`, нічого міняти не треба.
3. Кожна гілка отримує свою адресу попереднього перегляду — зручно показувати варіанти.

## Як роботу повернуть у програму

Структура тек — як у справжній програмі (`admin-frontend/`). Зміни переносяться в окрему гілку RosterMind,
перевіряються зі справжнім сервером і лише потім ідуть у роботу. Якщо дизайну потрібні нові дані — опишіть їх
у `docs/BACKEND_NEEDS.md`.
